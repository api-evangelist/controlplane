ControlPlane provides a virtual cloud platform that unifies compute, networking, identity, and services across multiple clouds, bare metal, and on‑prem environments. It enables teams to build, ship, and scale applications with AI‑native automation, universal cloud identity, and zero‑ops operations, offering high availability and compliance features for enterprise workloads.

**Areas:** Company · Cloud · Virtualization · Artificial Intelligence · DevOps

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ControlPlane: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
